## 4. 资料类型对照

| 类型 | 代表 | 权威性 | 覆盖 | 适合 |
|---|---|---|---|---|
| 讲义原文 | jyywiki | ★★★★★ | 13 讲 | 引用、核对定义 |
| 幻灯片 | jyywiki | ★★★★☆ | 14 讲 | 看课堂实际讲了什么、看图 |
| 课堂录像 | B 站 | ★★★★★ | 14 讲 | 完整语境、语气、现场演示 |
| 逐字稿 | Captions 仓库 | ★★★☆☆ | 13 讲 | 查原话、找讲义没写的例子 |
| 精读 | 软工星球 | ★★★☆☆ | 13 讲 | 入门、抓重点、自测 |
| AI 重写 | Argon | ★★☆☆☆ | 8 讲 | 系统通读、术语对照（需回查原文） |
| 模块整编 | Video2Book | ★★☆☆☆ | 7 集 | 按主题串联、做脑图 |
| 教案 | lesson-plans | ★★★☆☆ | 6 讲 | 备课、拆知识点 |

**引用优先级**：讲义原文 > 录像/逐字稿 > 精读 > AI 重写。二手材料里的事实性表述（版本号、论文名、数字）务必回查一手来源。

## 5. 本地整理产物

| 产物 | 形式 | 说明 |
|---|---|---|
| 主阅读器 | 单文件 HTML，2.8 MB | 五种读法（速览/讲义/精读/逐字稿/重写）+ 三级目录 + 跨五源搜索 |
| 课件 | HTML ×14 + Lab ×3 | 幻灯片本地化（MathJax、highlight.js 已内置），断网可用 |
| 打印版 | Word ×5 + PDF | 速览 15 页 / 精读 80 页 / 标注 86 页 / 细读 103+89 页 |
| 对照版 | HTML，502 KB | 逐字稿为骨架，讲义原文插入讲述位置 |
| 图文对照 | HTML + 426 张图，29 MB | 逐字稿为骨架，PPT 截图插入讲述位置 |
| 逐字稿全文 | Markdown | 13 讲合并 |
| 资料索引 | 本文档 | — |

整理脚本（Python，仅用标准库 + python-docx + playwright + pymupdf）：

```
extract_lectures.py    讲义正文提取（HTML → 片段）
extract_aux.py         精读 + 字幕提取
build_sections.py      按 H2 切节
build_site.py          主阅读器 + 总目录 + 讲义全文
build_docx.py          Word 打印版（5 份）
build_annotated.py     标注版（三层标注）
build_slides.py        课件本地化 + 索引
shoot_slides.py        PPT 逐页截图（Playwright）
build_interleave.py    讲义 × 逐字稿对照
build_ppt_interleave.py PPT × 逐字稿图文对照
md2html.py             极简 Markdown 渲染
```

## 7. 如果要开源，建议这样组织

```
gse-2026-notes/
├── README.md                  # 本文档（来源与说明）
├── LICENSE                    # CC BY-NC 4.0（衍生部分）
├── NOTICE.md                  # 各来源署名与许可清单
├── 讲义/                       # 13 讲讲义 Markdown（原作者内容，仅转载署名）
├── 逐字稿/                     # 13 讲校对口稿（来自 Captions 仓库）
├── 精读/                       # 软工星球精读（注明来源与许可）
├── 课件/                       # slides-01..14 + lab-1..3 + assets
├── 打印版/                     # 5 份 Word + PDF
├── 对照版/                     # 讲义×逐字稿.html
├── scripts/                   # 上述 Python 脚本
└── .gitignore                 # 排除 build/、图片缓存
```

**注意**：

1. 仓库体积。图文对照版含 426 张图（29 MB），Word 版也不小。建议 **Git LFS** 或只放 HTML/PDF，图片单独发布 Release。
2. 许可。CC BY-NC 4.0 允许转载与改编，但**必须署名且不得商用**。README 顶部和 NOTICE.md 都要写清。
3. 不要声称「官方」。仓库名与描述里避免出现「南京大学官方」「课程官方笔记」字样。

## 8. 复现步骤

```bash
# 1. 抓一手材料
curl -o lect1.md https://jyywiki.cn/GSE/2026/lect1.md        # 注意返回的是 HTML
for i in $(seq 1 14); do curl -o slides$i.html https://jyywiki.cn/GSE/2026/slides$i.html; done

# 2. 抓 GitHub 材料（github.com 直连不通时改用 API）
curl -L -o repo.tgz https://api.github.com/repos/NinZeige/NJU-2026-GSE-Captions/tarball/main

# 3. 提取与构建
python extract_lectures.py && python extract_aux.py && python build_sections.py
python build_site.py          # 主阅读器
python build_docx.py          # Word 打印版
python shoot_slides.py 1 2 3  # PPT 逐页截图
python build_ppt_interleave.py
```

依赖：Python 3.13、python-docx、playwright（用系统 Edge 即可，无需下载浏览器）、pymupdf。
